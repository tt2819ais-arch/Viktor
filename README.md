# Viktor — медиа-плеер

Тёмный, «жирный» (iOS-стиль), мультиязычный медиа-плеер на **React + Vite + TypeScript + Tailwind**.
Статическая сборка — кидаете `dist/` на любой хостинг и открываете без сборки на своём ПК.

🔗 Живая демо-версия (после первой сборки): `https://tt2819ais-arch.github.io/Viktor/`

---

## ✨ Возможности

- 🎵 **Музыкальный плеер** — плейлист, перемотка (drag), громкость, шафл, повтор (off/all/one), автопереход
- 🌑 **Тёмная / светлая тема** + 🌐 **языки RU / EN** (выбор запоминается)
- 🎬 **Фоновые видео** из папки `public/video` — играют в цикле, автосмена между ними
- 📝 **Субтитры/текст с таймингами** (`.vtt`) — текущая строка подсвечивается, клик = перемотка
- 📊 **Аудио-визуализатор** (Web Audio API), можно выключить
- ⌨️ **Горячие клавиши**: `Пробел` play/pause, `←/→` ±5с, `Shift+←/→` трек, `↑/↓` громкость, `M` mute, `N/P` след./пред.
- 🔒 **MediaSession** — управление с локскрина / наушников
- 📱 **Адаптив**: нижний tab-bar на телефоне, боковая навигация на ПК
- 🎚️ Мини-плеер на вкладках «Библиотека» и «Настройки»

## 📂 Как добавлять контент

> Музыку добавляет только тот, у кого есть доступ к исходному коду — через эти папки в репозитории.

| Папка | Что класть |
| --- | --- |
| `public/music/` | Аудио: `mp3, m4a, aac, ogg, wav, flac, opus`. Имя `Исполнитель - Название.mp3` распарсится автоматически. |
| `public/video/` | Фоновые видео: `mp4, webm, ogv`. Сколько угодно — играют в loop. |
| `public/subtitles/` | `.vtt` с таймингами. Имя файла должно совпадать с именем трека, чтобы подцепиться. |

Пример связки субтитров с треком:
```
public/music/Aurora - Night Drive.mp3
public/subtitles/Aurora - Night Drive.vtt
```

После добавления файлов **манифест генерируется автоматически** при сборке
(`scripts/generate-manifest.mjs` запускается из `vite.config.ts`). Руками ничего прописывать не нужно.

## 🛠 Локальный запуск

```bash
npm install
npm run dev      # дев-сервер
npm run build    # прод-сборка в dist/
npm run preview  # локальный предпросмотр собранного
```

Требуется Node 20+.

## 🚀 Автосборка в GitHub Actions

Workflow `.github/workflows/deploy.yml` при каждом push в `main`:

1. ставит зависимости и собирает сайт (`npm ci && npm run build`);
2. выкладывает артефакт **`site-dist`** — zip с готовым `dist/`, можно скачать во вкладке Actions и закинуть на любой хостинг;
3. деплоит на **GitHub Pages** — сразу живой URL, без сборки на вашем ПК.

### Включить GitHub Pages (один раз)
Settings → Pages → **Source: GitHub Actions**. После этого каждый push в `main` обновляет сайт.

## ⚙️ Технические детали

- `base: "./"` — один и тот же билд работает и на GitHub Pages (подпуть), и на вашем хостинге из корня домена.
- Бэкенда нет — чистая статика. Медиа отдаётся как обычные файлы из `public/`.
- Визуализатор использует общий `AnalyserNode`; аудио-граф создаётся при первом нажатии Play (политика автоплея браузеров).
- Шрифт — системный SF Pro / system-ui, везде жирные начертания (700–800).
- Иконки — [lucide-react](https://lucide.dev) (монохром, один штрих).
- Анимации — [framer-motion](https://www.framer.com/motion/).
