# Музыка / Music

Положите сюда аудиофайлы (mp3, m4a, flac, ogg, wav, opus…).

- Имя файла `Исполнитель - Название.mp3` распарсится автоматически.
- После добавления просто запустите сборку (`npm run build`) или push в `main`
  — манифест перегенерируется сам, файлы появятся в плеере.
