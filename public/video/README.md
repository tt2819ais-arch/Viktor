# Фоновые видео / Background videos

Положите сюда видео (mp4, webm, ogv). Они проигрываются в цикле как фон сайта.
Можно сколько угодно — в настройках доступна автосмена между ними.

Drop background videos here (mp4, webm, ogv). They loop behind the app.
